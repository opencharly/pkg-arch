# 2026.268.1406 — docs(task): rewire the pkg-arch Taskfile-era task references

## Summary

Sweep the stale Taskfile-era task references in the Arch packaging repo after the
superproject's Taskfile→`charly task` cutover.

- `PKGBUILD`, `README.md`, `calver.sh`, `opencharly-git.install` now reference
  `scripts/bootstrap-charly.sh` (the ONE non-charly bootstrap build) instead of
  the deleted `task build:binary` / `task build:install-portable` /
  `task build:pkg:arch` targets;
- the vestigial `go-task` optdepend and the `opencharly-git.install` block that
  symlinked `/usr/local/bin/task` are removed — charly no longer needs `go-task`
  since charly#651 deleted the Taskfile;
- `README.md`'s `cd pkg/arch` corrected to the umbrella submodule path
  `pkg-arch`, and the `build:pkg:arch` sentence replaced with an accurate
  statement (that target was deleted in charly 29c5140e, so the old sentence was
  doubly stale).

The removal of the `go-task` optdepend and the post-install symlink block IS a
packaging metadata / install-script behavior change, gated below.

Note for the concurrent packaging PRs (#22/#23/#24, `feat/nerdctl-packaging-*`):
they edit the same `PKGBUILD` regions, so this branch and those will conflict in
`PKGBUILD` — the task-reference sweep here should be preserved when they rebase.

## How tested

**Real fresh package build** (`makepkg -f` against the local-source tree; the
package's `source=` resolves the surrounding charly checkout, whose
`bin/charly` was refreshed by `scripts/bootstrap-charly.sh` first):

```
$ ./scripts/bootstrap-charly.sh            # in the charly source worktree
bootstrap-charly: built ./bin/charly (2026.268.1148)

$ makepkg -f --noconfirm
==> Creating package "opencharly-git"...
==> Finished making: opencharly-git 2026.268.1148-1
(exit 0)
```

**The built package's metadata + shipped install script carry the change** —
`go-task` is gone from `.PKGINFO`, and the shipped `.INSTALL` no longer symlinks
`/usr/local/bin/task`:

```
$ tar -xOf opencharly-git-2026.268.1148-1-x86_64.pkg.tar.zst .PKGINFO | grep -c '^optdepend'
9
$ tar -xOf opencharly-git-2026.268.1148-1-x86_64.pkg.tar.zst .PKGINFO | grep go-task
(absent)
$ tar -xOf opencharly-git-2026.268.1148-1-x86_64.pkg.tar.zst .INSTALL | grep -cE 'go-task|/usr/local/bin/task'
0
```

**The packaged binary runs and reports its version:**

```
$ tar -xOf opencharly-git-2026.268.1148-1-x86_64.pkg.tar.zst usr/bin/charly > /tmp/packaged-charly && chmod +x /tmp/packaged-charly
$ /tmp/packaged-charly version
2026.268.1148
```

**PKGBUILD parses and the optdepend set is as intended:**

```
$ makepkg --printsrcinfo | grep -c optdepend
9
```

**The claim-keyed sweep returns no stale reference:**

```
$ grep -rnE '\btask (build:binary|build:pkg:arch|build:install-portable|build:charly|install|install-arch)\b|Taskfile|taskfiles/|go-task' . | grep -v '^./CHANGELOG/'
(empty)
```

## Rulebook compliance

- **R5 (delete legacy completely):** the removed task names are swept across all
  tracked packaging files; only `CHANGELOG/` retains them as history.
- **The replacement claim carries the removal's burden of proof:** the
  `build:pkg:arch` and `go-task` replacements were traced to the commits that
  removed the old surfaces (charly 29c5140e, charly#651) before being written.
- **R4a:** the README no longer directs readers to a checkout-relative command as
  product guidance.

- **Change class:** packaging config + install-script behavior (removal of a dead
  optdepend and its post-install symlink block) plus documentation sweeps — not
  documentation-only.
- **Verification gate:** a real fresh `makepkg -f` build of the changed PKGBUILD,
  with the built package's `.PKGINFO`/`.INSTALL`/`usr/bin/charly` inspected live.
